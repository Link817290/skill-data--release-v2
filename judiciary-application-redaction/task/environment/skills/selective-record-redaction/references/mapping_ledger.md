# Selective Redaction Ledger

Keep this scratch ledger outside the output directory.

| Source page and prompt | Representation | Exact response region | Decision class | Action code | Reason tied to purpose | Verified after save |
| --- | --- | --- | --- | --- | --- | --- |
| page, section, nearby label | widget, text, vector mark, handwriting, image | page-coordinate rectangle | retain-professional, retain-administrative, alias, redact-direct, redact-declaration | stable code or retained | why the review needs or excludes it | object, label, and pixel result |

The ledger is closed only when every nonempty widget and every visible entered mark has one decision. Printed labels and instructions need not be listed unless an edit rectangle could affect them. Reconcile the action-code counts against the control summary after editing.
