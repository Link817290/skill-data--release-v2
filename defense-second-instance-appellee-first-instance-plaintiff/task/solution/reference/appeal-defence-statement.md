民事答辩状
答辩人：A公司，住所地某市某开发区某道路某号。
法定代表人：甲。

对B公司与A公司建设工程施工合同纠纷一案【案号：（2023）某****民终****号】，A公司现依据事实与法律，针对B公司提出的上诉请求提交答辩意见如下：
针对B公司的诉请，原审法院对案涉工程价款、逾期付款违约金、工程质保金及逾期支付利息的判决并无不当
一、原审法院对案涉工程价款的判决并无不当
（一）原审法院采纳鉴定机构C公司作出的《工程造价鉴定意见》（以下简称“《鉴定意见》”），认定沉井工程系工程变更，应当增加工程造价约442万元并无不当
1.沉井工程不属于《某大道跨某河道桥梁工程（施工总承包）建设项目施工合同》（以下简称“《施工合同》”）专用条款12.1条约定的基坑支护措施工程
首先，沉井工程是一种实体工程，其与承台、桥墩一起构成桥梁的下部受力系统，作用在于从水平、竖向两个方向保证整个桥梁工程主体及基础部分的稳定性，尽管其从一定程度上亦可作为基坑支护的一种措施，但其更重要的功能在于最终稳定于土体内部，形成构筑物的一部分，而12.1条约定的钢板围护仅能作为一种阶段性的措施工程，最终会被拆除，无法成为桥梁主体工程的一部分，因此B公司将二者混为一谈是不合理的。
退一步来说，即使B公司坚持认为沉井工程只是单纯的围护结构，其与《施工合同》中约定包干的钢板也是两种完全不同的措施工程，二者无论组价原则还是综合单价都差异巨大，不能因为12.1条中约定了基坑支护的钢板围护费用包干，就认定对沉井围护也不予调价，否则，12.1条将所有工程变更的风险完全转嫁于议价能力较弱的承包人A公司是明显有失公平的。
2.沉井工程属于工程变更，鉴定机构依据双方签订的《施工合同》专用条款10.4.1条第（2）款计算工程价款并无不当
案涉沉井不属于原清单已有项目。其施工内容、功能和计价基础均不同于清单所列围护措施，属于应依合同第10.4.1条结合实际工程量重新组价的变更项目。
综上所述，原审法院采纳该《鉴定意见》关于沉井工程的鉴定结论，增加工程造价约442万元并无不当。
（二）原审法院采纳鉴定机构C公司作出的《鉴定意见》，认定高压水泥旋喷桩作为工程漏项重新组价，应当增加工程价款并无不当
1.高压水泥旋喷桩属于工程量清单漏项，鉴定机构依据《施工合同》专用条款10.4.1条第（2）款重新组价并无不当
原招标清单仅列深层水泥搅拌桩，并无高压旋喷桩项目。两种桩型施工工艺和计价基础不同，高压旋喷桩属于清单漏项，应依合同第10.4.1条重新组价。
因此鉴定机构依据专用条款10.4.1（2）条重新组价并无不当，原审法院采纳相应《鉴定意见》亦属合理。
（三）原审法院采纳鉴定机构C公司作出的《鉴定意见》，认定混凝土灌注桩由原约定的回旋钻机施工变更为旋挖钻机及冲锤桩基施工应当增加相应工程造价并无不当
对B公司所称地质条件未发生变化的上诉理由，应以鉴定所审查的实际地质资料为准；如实际地质与勘察资料不符并导致原机械不适用，改用旋挖及冲锤设备即不属于承包人自行改变工法。
首先，根据《施工合同》通用条款2.4.3条，提供准确地质勘察资料是发包人B公司的责任。因地勘资料与现场地质不符而改变机械并产生额外费用，不应归责于承包人A公司。
因此，机械改变源于地质条件与地勘资料不符，并非承包人自行选择施工方法；依合同第10.4.1条重新组价并无不当。
（四）原审法院采纳鉴定机构C公司作出的《鉴定意见》，按照2017年11月至2020年10月之间的信息价计算本工程结算价款并无不当
鉴定采用2017年11月至2020年10月的实际施工期间信息价。B公司虽主张因工期延误应改用合同价格，但延误责任及该价格条款的适用前提未经证明。因此，采用实际施工期间信息价具有事实和合同依据。B公司在原审亦未就工期违约金提出反诉。
综上所述，鉴定机构C公司出具的《鉴定意见》事实清楚，鉴定依据明确，计算过程准确，原审法院采纳《鉴定意见》作出裁判并无不当。
二、原审法院以一审起诉日次日作为工程款逾期付款违约金起算点并无不当
（一）A公司提交结算材料后，B公司从未出具其签认的结算价款，因此不能适用《施工合同》专用条款14.2条第（3）款及第20条争议解决条款
《施工合同》专用条款14.2条第（3）款约定“承包人对发包人签认的结算价有异议的，发包人可先支付承包人无异议部分结算款。异议部分重新进行复核或按照第20条[争议解决约定处理]”。亦即，只有在B公司出具其签认的明确的结算价并且完成双方无异议部分的付款后，剩余的争议部分才能适用争议解决条款。然而，自A公司2021年1月提交结算材料后，B公司持续拖延结算进度，也未曾出具发包人认可的结算价，现有记录无法确认双方无争议部分及其付款机制已经形成，该条款的适用前提并未闭合，更不可能因此免除B公司逾期支付工程款的违约责任。因此，原审法院对该条款未予采信并无不当。
（二）B公司拒绝出具竣工结算证书，导致专用条款14.2条第（2）款约定的付款起算时间不明确。以A公司实际提起一审诉讼之日作为付款到期认定基准、并自次日起算违约金，符合到期日无法依结算证书确定时的处理原则
《施工合同》专用条款14.2条第（1）款约定发包人原因逾期审核应向承包人支付违约金，但该条款并非第（2）款逾期支付工程款的前置条件，因此B公司主张其已将结算资料提交审计单位并不能当然免除其逾期支付工程结算款的违约责任。
此外，14.2条第（2）款约定工程结算款的支付时点为发包人签发竣工结算证书后14日内，但由于B公司拖延结算，未能在指定期间内出具竣工结算证书，导致违约金起算时点难以确定。原审法院参照《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》第二十七条关于逾期支付工程款利息的约定，以A公司起诉之日作为应付款日，并自次日即2021年8月20日作为逾期支付违约金起算点并无不当。
三、原审法院未予认定案涉工程的工期延误违约金并无不当
B公司在原审中未提出工期延误违约金的反诉请求，故该项违约金不能在本次上诉中直接抵销A公司的工程款请求，原审不予采纳并无不当。
综上所述，B公司提出的上诉请求并无合理依据，请求依法驳回其上诉请求，维持原判，并由B公司承担本案二审诉讼费用。
此致
某中级法院
