民事答辩状
答辩人：A公司，住所地某市某开发区某道路某号。
法定代表人：甲。

对B公司与A公司建设工程施工合同纠纷一案【案号：（2023）某****民终****号】，A公司现依据事实与法律，针对B公司提出的上诉请求提交答辩意见如下：
针对B公司的诉请，原审法院对案涉工程价款、逾期付款违约金、工程质保金及逾期支付利息的判决除未考虑水泥价格调差费用约135万元及相应的违约金、利息费用外并无不当
一、原审法院对案涉工程价款的判决除未考虑水泥价格调差费用约135万元及相应的违约金、利息费用外并无不当
（一）原审法院采纳鉴定机构C公司作出的《工程造价鉴定意见》（以下简称“《鉴定意见》”），认定沉井工程系工程变更，应当增加工程造价约442万元并无不当
1.沉井工程不属于《某大道跨某河道桥梁工程（施工总承包）建设项目施工合同》（以下简称“《施工合同》”）专用条款12.1条约定的基坑支护措施工程
首先，沉井工程是一种实体工程，其与承台、桥墩一起构成桥梁的下部受力系统，作用在于从水平、竖向两个方向保证整个桥梁工程主体及基础部分的稳定性，尽管其从一定程度上亦可作为基坑支护的一种措施，但其更重要的功能在于最终稳定于土体内部，形成构筑物的一部分，而12.1条约定的钢板围护仅能作为一种阶段性的措施工程，最终会被拆除，无法成为桥梁主体工程的一部分，因此B公司将二者混为一谈是不合理的。
退一步来说，即使B公司坚持认为沉井工程只是单纯的围护结构，其与《施工合同》中约定包干的钢板也是两种完全不同的措施工程，二者无论组价原则还是综合单价都差异巨大，不能因为12.1条中约定了基坑支护的钢板围护费用包干，就认定对沉井围护也不予调价，否则，12.1条将所有工程变更的风险完全转嫁于议价能力较弱的承包人A公司是明显有失公平的。
2.沉井工程属于工程变更，鉴定机构依据双方签订的《施工合同》专用条款10.4.1条第（2）款计算工程价款并无不当
2018年6月，B公司指令设计单位向A公司发出《D公司设计业务联系单（编号****）》，该设计联系单明确载明“本工程桥墩PA02、PA03、PB02、PB03（共8座）埋深极深，桥墩承台底部埋深约9.5m，根据现场实际情况，补充桥墩承台施工围护结构。”并出具了相应的《桥墩承台沉井设计施工图》，后续A公司按照设计要求完成施工并通过了隐蔽工程验收。
根据《施工合同》通用条款10.1（1）条，额外增加的8个沉井属于工程变更，由于《建设工程咨询报告书》（以下简称“原招标清单”）中并不存在相同或类似的项目，因此鉴定机构依据《施工合同》专用条款10.4.1条第（2）款对沉井工程重新组价并依据实际工程量计算工程造价并不不当。
综上所述，原审法院采纳该《鉴定意见》关于沉井工程的鉴定结论，增加工程造价约442万元并无不当。
（二）原审法院采纳鉴定机构C公司作出的《鉴定意见》，认定高压水泥旋喷桩作为工程漏项重新组价，应当增加工程价款并无不当；但原审法院未考虑水泥价格调差（约135万元）对工程造价的影响，在二审中应当予以改判纠正
1.高压水泥旋喷桩属于工程量清单漏项，鉴定机构依据《施工合同》专用条款10.4.1条第（2）款重新组价并无不当
2018年10月，A公司向B公司提交了《工程联系单》，该联系单中双方就挡土墙基底地基处理采用高压旋喷桩施工一事达成了共识，B公司亦在附件《挡墙基础高压旋喷桩平面布置图》上盖章认可。但由于原招标清单仅有深层水泥搅拌桩一项，而无高压水泥旋喷桩项目，属于《施工合同》通用条款10.1（3）条约定的工程量清单漏项。
此外，2018年11月，A公司就高压水泥旋喷桩重新组价事宜再次向B公司提交了《工程联系单》，该联系单中清晰载明“根据工作联系单要求挡土墙基底地基处理采用高压旋喷桩施工，根据原设计图纸高压旋喷桩施工参数为∶有效桩长20m，桩径0.6m，采用42.5R级普通硅酸盐水泥，水泥掺量200kg/m，单管注浆。因原投标工程量清单项目无相同项目，现根据合同专用条款10.4.1之规定，另行计算综合单价（其中42.5散装水泥按2018年11月《某市造价》的某市市区信息价）。”该《工程联系单》上监理及建设单位B公司均已签字认可。
因此鉴定机构依据专用条款10.4.1（2）条重新组价并无不当，原审法院采纳相应《鉴定意见》亦属合理。
2.鉴定机构在《鉴定意见》中明确写明，“如考虑水泥价格调差，应当增加工程造价约135万元”。原审法院认定双方未就水泥价格调差达成合意，不予增加工程造价属于事实认定错误，应当予以纠正
对于水泥价格调差问题，核心的争议点在于B公司是否以签字盖章的形式表示了对整个联系单（包括附件）的认可，该问题并非造价问题，而是法律问题，因此鉴定机构以争议项的形式列明，最终应当由原审法院基于意思表示及民法诚实信用原则的理论对其作出解释和判定。
根据《民法典》第一百四十二条，意思表示的解释应当结合相关条款、行为的性质和目的、习惯以及诚信原则来确定。根据双方平时的签证习惯，B公司并不会在“建设单位意见”部分详细就联系单内容一一进行确认，通常是以“情况属实”、“同意监理意见”等形式对整张《工程联系单》作出确认的意思表示。因此，在无相反的意思表示情况下，应当认为当事人的签字是对整个签证内容的认可，即双方已就高压旋喷桩水泥价差调整达成一致意见。
另外，相比于2017年3月的招标基准价（330元/吨），开工以来，水泥价格出现暴涨，2018年全年价格都在450元以上，11月甚至达到了603元/吨（不含税价），为招标时基准价格的1.8倍。水泥作为高压旋喷桩的主材，单此一项导致的价格差异就超过了135万。如不顾市场情况，不予认可价格的调整，对于A公司来说是极不公平的。 
因此，原审法院未考虑水泥价格调差（约135万元）对工程造价的影响是不准确的，应当在二审中予以改判纠正。
（三）原审法院采纳鉴定机构C公司作出的《鉴定意见》，认定混凝土灌注桩由原约定的回旋钻机施工变更为旋挖钻机及冲锤桩基施工应当增加相应工程造价并无不当
施工混凝土灌注桩过程中，由于现场地质实际情况与地勘资料不相符，A公司发现回旋钻机无法施工。经与B公司及监理、设计、勘察单位等共同讨论协商后，A公司将施工机械更换为旋挖钻机和冲锤桩机。
2018年8月，A公司向B公司提交了《工程联系单》及附件，该联系单中清晰载明“采用XR360旋挖钻机挖捞出的石样粒径20cm左右的较多（见照片），超过勘探报告所显示的4-10cm，进一步确认了圆砾较大的实际情况。”并约定“旋挖钻机施工桥墩φ1500灌注桩36根，综合单价按10.4.1.（2）条款重新组价。 冲锤桩机施工桥墩φ1500灌注桩1根（PB03-1#桩），综合单价按10.4.1.（2）条款重新组价。”监理单位及建设单位B公司均在联系单上签证认可。
首先，根据《施工合同》通用条款2.4.3条的约定，提供准确的地质勘察资料是发包人B公司的责任。因此因地勘资料出现错误导致工程变更，且产生额外的工程费用，责任应当由义务方B公司承担。而圆砾层位于地表以下超过60m深度处，该错误也不可能通过A公司对于现场的初步勘探发现，因此A公司不应承担因地勘报告不准确产生的不利后果。
其次，双方业已就该问题进行详细的签证，《工程联系单》及附件中对于工程变更的原因，变更组价的原则都进行了明确的约定。
因此，《鉴定意见》依据《工程联系单》及附件中的约定，依据《施工合同》专用条款10.4.1（2）条进行重新组价并无不当，原审法院采纳相应《鉴定意见》亦属合理。
（四）原审法院采纳鉴定机构C公司作出的《鉴定意见》，按照2017年11月至2020年10月之间的信息价计算本工程结算价款并无不当
2022年1月，双方当事人签署了《鉴定笔录确认表》。《鉴定笔录确认表》第4点明确说明，本工程造价鉴定采用的信息价期间为2017年11月至2020年10月。因此，B公司已经认可了鉴定的信息价期间。答辩人全程参与了鉴定程序并在现场查勘记录上签字。
此外，B公司主张由于A公司工期延误要求按照《施工合同》专用合同16.2.2条第5项约定来确定信息价，但并未提供证据且原审中未提起反诉。因此，鉴定中采用的信息价时间跨度（2017年11月至2020年10月）是符合双方当事人约定并且合理的，原审法院采纳相应《鉴定意见》并无不当。
综上所述，鉴定机构C公司出具的《鉴定意见》事实清楚，鉴定依据明确，计算过程准确，除将水泥价格调差列为争议事项外，该《鉴定意见》对案涉工程的工程造价计算是合理的。原审法院采纳《鉴定意见》作出裁判，除未考虑水泥价格调差费用导致的工程造价增加外并无不当。
二、原审法院认定B公司应当自2021年8月（一审起诉之日）起按《施工合同》专用条款14.2条第（2）款的约定向A公司支付工程款逾期支付违约金并无不当
（一）A公司提交结算材料后，B公司从未出具其签认的结算价款，因此不能适用《施工合同》专用条款14.2条第（3）款及第20条争议解决条款
《施工合同》专用条款14.2条第（3）款约定“承包人对发包人签认的结算价有异议的，发包人可先支付承包人无异议部分结算款。异议部分重新进行复核或按照第20条[争议解决约定处理]”。亦即，只有在B公司出具其签认的明确的结算价并且完成双方无异议部分的付款后，剩余的争议部分才能适用争议解决条款。然而，自A公司2021年1月提交结算材料后，B公司持续拖延结算进度，也未曾出具发包人认可的结算价，现有记录无法确认双方无争议部分及其付款机制已经形成，该条款的适用前提并未闭合，更不可能因此免除B公司逾期支付工程款的违约责任。因此，原审法院对该条款未予采信并无不当。
（二）B公司拒绝出具竣工结算证书，从而导致专用条款14.2条第（2）款的起算时间不明确，原审法院酌情以A公司起诉之日作为应付款日，并自次日即2021年8月20日作为违约金起算点并无不当
《施工合同》专用条款14.2条第（1）款约定发包人原因逾期审核应向承包人支付违约金，但该条款并非第（2）款逾期支付工程款的前置条件，因此B公司主张其已将结算资料提交审计单位并不能当然免除其逾期支付工程结算款的违约责任。
此外，14.2条第（2）款约定工程结算款的支付时点为发包人签发竣工结算证书后14日内，但由于B公司拖延结算，未能在指定期间内出具竣工结算证书，导致违约金起算时点难以确定。原审法院参照《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》第二十七条关于逾期支付工程款利息的约定，以A公司起诉之日作为应付款日，并自次日即2021年8月20日作为逾期支付违约金起算点并无不当。
三、原审法院未予认定案涉工程的工期延误违约金并无不当
B公司在原审中从未提出工期延误违约金的反诉请求，双方亦未就工期延误的事实进行举证与辩论，原审法院对B公司提出的工期相关抗辩不予采纳并无不当。
综上所述，B公司提出的上诉请求并无合理依据，望合议庭依法驳回其上诉请求。
