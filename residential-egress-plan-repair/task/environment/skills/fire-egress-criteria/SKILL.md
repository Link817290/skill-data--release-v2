# Fire-egress criteria

Read the supplied code as a hierarchy, not as a bag of numbers. First classify the building and the route being reviewed. Then collect only clauses whose subject, occupancy, and floor condition match that classification. A nearby table or a more restrictive branch is not controlling unless its scope reaches the reviewed element.

## Build a clause ledger

For every adopted rule, record:

- the exact file and printed page or clause;
- the object to which it applies (door, route, stair, exit, or another element);
- the quantity type (clear width, total width, distance, or count);
- the unit and any conversion convention;
- whether it is a minimum, maximum, or conditional rule;
- the condition that activates or limits the rule.

Keep "total required width" separate from "minimum width of one element". Do not satisfy a minimum door width by adding a corridor width, and do not treat a route-wide calculation as permission to narrow an individual opening.

## Resolve competing text

When two clauses appear relevant, write the applicability reason for the selected one and the exclusion reason for the other. If a required input such as occupant load, building height, or exit count is absent, carry the item as unresolved rather than manufacturing an assumption. An unresolved item should have an owner/action in the memo and must not be drawn as a completed controlling repair.

## Evidence language

Bind each finding to the clause that governs it and to the drawing geometry that was observed. A citation that names only the document is not reproducible. Use stable printed-page and clause references, quote short identifying terms when helpful, and state the unit conversion beside the measured value.
