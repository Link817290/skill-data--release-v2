# 民事答辩状

**答辩人**：B公司，住所地某市某区某街道某路某号，组织机构代码信用代码2。

**法定代表人**：乙，董事长。

针对A公司与B公司委托创作合同纠纷一案【案号：案号1】，B公司现依据事实与法律，针对A公司提出的诉讼请求提交答辩意见如下：

## 一、关于原告请求支付合同全部价款1482040元的诉讼请求，缺乏事实与法律依据，不应得到支持

- 2022年4月27日，原被告双方就某商业街区商铺改造及装饰项目工程裸眼3D大屏的3D裸眼视角视频制作项目签订《某商业街区商铺改造及装饰项目工程裸眼3D视频制作采购合同》（下称“采购合同”）。

- 由于采购合同所涉的3D裸眼视角视频系用于C公司（下称C公司）的某商业街区商铺，因此采购合同第3.7条专门约定“所有视频内容和视频质量须经C公司确认，乙方向C公司递交确认函，待C公司确认合格后方可付款”，第7.1条约定“乙方完成各阶段工作任务后，应通知甲方对工作成果进行接收。乙方及时将建设单位的确认函提交给甲方”。截止答辩之日，原告既未按合同约定向被告提交C公司的书面确认函，亦未能证明二期视频成果已获得C公司的确认。经被告向C公司核实，C公司与原告就一、二期视频共同统筹结算达成合意，而在原告交付的二期视频并未得到确认的情况下，被告付款条件并未成就，被告不具备付款义务。

## 二、原告主张被告支付逾期付款违约金的诉讼请求，缺乏事实与法律依据，不应得到支持

- 首先，如前所述，原告交付的视频未得到C公司确认，原告未向被告提交符合合同要求的确认函，被告付款条件尚未成就，原告请求支付逾期付款违约金缺乏事实与法律依据。

- 另外，采购合同第9.2条还约定“在支付合同价款前，乙方应按甲方要求出具与经济业务相符合法有效的增值税专用发票”“乙方未能提供发票或提供假发票的，甲方有权拒绝支付相应款项”，在原告尚未出具符合合同要求的发票的情况下，被告有权拒绝支付相应款项。

- 至于合同第9.4条约定的“违约金”（包括拖延支付货款期间的违约金以及加付违约金），其适用条件为“因甲方（被告）原因不按时支付货款”。根据采购合同约定，原告也明知被告需根据C公司的指令向原告付款，在C公司未对原告成果予以确认的情况下，被告既无权利也无义务径行付款。被告对此不存在过错，未及时付款也非被告原因，因此不应承担该条款约定的任何违约责任。

- 即便法院认定被告需承担逾期付款责任，合同约定的违约金计算标准亦明显超出原告的实际损失，请求法院依据《民法典》第五百八十五条的规定，结合合同的履行情况、当事人的过错程度以及预期利益等综合因素，遵循公平原则和诚实信用原则，对违约金予以调减。

- 综上所述，原告主张全部合同价款及逾期付款违约金，缺乏合同依据与事实基础。恳请贵院依法查明事实，驳回原告不合理的诉讼请求，以维护被告的合法权益。
