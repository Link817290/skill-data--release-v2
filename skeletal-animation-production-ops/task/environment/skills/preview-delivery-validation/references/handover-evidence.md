# Handover evidence checklist

| Evidence | Check | Limit |
|---|---|---|
| Project | Entry point and runtime dependencies resolve | Loading alone does not prove correct behavior |
| Assets | Required hashes and indices remain intact | Disk identity does not prove runtime use |
| Invocation | Launcher, exporter, project and destination are concrete | Never execute arbitrary register text as code |
| Trace | Complete observation window and real object/event samples | Candidate status flags need independent support |
| Preview | Fresh export agrees and artwork is visible as required | Self-consistency does not establish correctness |
| Register | Ticket, supported outcome, changed area and resolving paths | Automated checks cannot fully judge prose quality |

Keep path resolution inside the intended delivery root. Accept equivalent argument order and quoting when interpreting a known exporter command. Report unsupported render features explicitly. Preserve an evidence index with artifact location, producer, observation scope and validation result.
