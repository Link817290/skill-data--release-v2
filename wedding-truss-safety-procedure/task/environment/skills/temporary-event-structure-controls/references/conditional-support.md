# Conditional Support Decisions

Use this reference when a source provides a height table, suspended-load increment, floor or wind adjustment, or a brace reduction. Read the source's stated scope first: an experience table for a regular backdrop is not a structural rating for every topology or loading condition.

For each supported configuration, record the object and units, select the applicable base band, then list each genuinely applicable additive adjustment and bounded reduction. Retain minimum limits after reductions. Where a boundary overlaps, adopt a defensible conservative case or make the uncertainty explicit; do not silently choose the least ballast. Where a parameter has not been provided, write a conditional rule rather than inventing a site value.

Distinguish frame members, individual support posts and shared spans. A suspended load on a beam cannot automatically be assigned equally to supports without a load path. Specify contact, leveling, symmetric ballast placement and restraint alongside the nominal weight. An adequate mass does not cure an unsupported edge, a sliding base or a disconnected brace.

Cross-check any combined rule against the source's scope. If the layout exceeds the source envelope, has unusual concentrated loads, dynamic forces or uncertain supports, call for a qualified design and do not label a quick check a certified installation. An approved system-specific specification takes precedence over a generic heuristic.

Verification: trace a base-case branch, a branch with an added load and a branch with a permitted reduction. Confirm that they change only the applicable terms, preserve minimum controls and lead to an observable support inspection. These are planning checks and do not establish that a real inspection has happened.
