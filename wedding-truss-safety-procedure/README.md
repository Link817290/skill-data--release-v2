# Wedding Truss Safety Procedure

Author a Chinese DOCX procedure for hotel wedding-truss planning, incoming
inspection, assembly, electrical work, acceptance, ceremony response,
dismantling, restoration, and handover.

The actor image uses `harbor-claude-code-aggregated:1.3`. Run
`task/solution/solve.sh --out <directory>` for the Oracle and
`task/tests/test.sh` for mixed evaluation. The program judge measures explicit
safety relations, including relations split across lifecycle sections, and the
source-bound semantic judge accepts professional equivalents.
