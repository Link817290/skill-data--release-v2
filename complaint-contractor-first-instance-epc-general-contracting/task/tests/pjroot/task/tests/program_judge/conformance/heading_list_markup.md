## 一、诉讼请求：

1. 判决被告B公司与原告A公司签订《建设项目工程总承包合同》自起诉状副本送达被告时解除。

2. 判决被告B公司向原告A公司赔付损失17,994,231.87元，并判决自合同解除之日起按中国人民银行授权的同业拆借中心公布的同期贷款市场报价利率向原告A公司支付资金占用费至实际清偿之日。

3. 判决被告C公司对被告B公司的全部债务承担连带责任。

4. 判决被告B公司、被告C公司承担本案全部案件受理费、财产保全费等相关诉讼费用。

## 二、事实和理由：

2020年7月15日被告B公司（简称“B公司”）与原告A公司（简称“A公司”）依法签订《工程总承包合同》，承包范围包括对案涉项目的设计（含初步设计、施工图设计）、采购、施工、试运行、竣工验收及专项验收、检测、竣工备案等实行全过程承包；合同价格形式为总价包干合同，价格为A公司的投标总价，具体包括一期设计费500万、二期设计费480万、一期施工费24868.616535万及二期施工费22769.198829万，合计48617.815364万元。A公司按中标价支付中标服务费17500元。

2022年5月6日案涉项目一期完成竣工验收。现有材料未充分证明一期工程结算款及质保金已全部支付，本案二期解除损失主张不以该事项为既定事实。

### 一、B公司违约解除合同，应承担违约责任。

证据目录将2024年5月22日招标计划指认为案涉二期，但该计划底层文件标注为“某药物非临床研究中心一期建设项目”，与案涉“某医疗孵化基地二期”项目名称、分期均不相同，不能直接据此认定二期已另行招标；2024年7月8日B公司向A公司发送《合同部分解除通知书》，通知不再实施二期工程；2024年10月16日D公司就案涉项目二期以同样的EPC形式公开招标，11月25日E公司以21304.120641万元的价格中标。

因B公司不享有合同解除权，故其擅自将案涉项目二期转由他人实施，并通知A公司解除部分合同的行为构成根本违约。该违约行为不仅损害了A公司的合法权益，更是严重扰乱了建筑业市场的秩序，破坏了诚实信用的价值体系。

根据《民法典》第五百八十四条规定：“当事人一方不履行合同义务或者履行合同义务不符合约定，造成对方损失的，损失赔偿额应当相当于因违约所造成的损失，包括合同履行后可以获得的利益”，B公司应向A公司赔偿违约所造成的损失，包括合同履行后可以获得的利益。至B公司发函之日，A公司已完成二期初步设计文件，并已按B公司要求完成开工仪式的典礼准备工作，实施了案涉项目所需的全部施工便道、便桥、砖墙、围挡、办公区、工人宿舍、讲话台、宣传栏、车辆冲洗平台、钢筋加工厂等临时设施。

因此，B公司应赔偿的损失具体包括：1.二期初步设计费1,680,000元；2.二期临时设施费2,583,218.16元；3.预期利润【待核定】元；4.二期分摊的中标服务费8,487.5元。上述损失赔偿额合计17,994,231.87元。

### 二、B公司应自合同解除之日向A公司支付资金占用费。

根据《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》第二十五条规定，A公司有权请求B公司支付资金占用费，资金占用费应自合同解除之日按照中国人民银行授权全国银行间同业拆借中心公布的一年期贷款市场报价利率（LPR）计算至B公司向A公司付清全部应付款项之日止。

### 三、母公司C公司应对其全资子公司B公司的债务承担连带责任。

B公司是一人有限公司，根据《公司法》第二十三条第三款的规定：“一人有限责任公司的股东不能证明公司财产独立于股东自己的财产的，应当对公司债务承担连带责任”，B公司的股东C公司应当对B公司的债务承担连带责任。

综上，为维护原告A公司的合法权益，特向贵院提起诉讼，请贵院在查清事实的基础上，依法判如所请。
