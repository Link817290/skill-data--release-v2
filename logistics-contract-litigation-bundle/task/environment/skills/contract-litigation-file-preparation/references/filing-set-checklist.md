# Filing set checklist

## Complaint

Identify the parties and court, plead the contract and event timeline, state the requested relief, connect each requested remedy to the asserted breach, and distinguish fixed contractual relief from losses that still require proof.

## Evidence list

Give each source a neutral name and a bounded proof purpose. The proof purpose must not claim more than the source can establish. Keep allegations, denials, and observed events separate.

## Case handoff

Record the client objective, dispute type, core timeline, requested relief, received materials, and unresolved intake fields. It should let another professional reconstruct the case theory without reading conclusions unsupported by the record.

## Court forms

Carry over only supported party, address, phone, and payee information. Leave court-assigned case numbers, signatures, dates of signing, identity numbers, bank names, and account numbers unresolved unless the record provides them for the exact field.

## Cross-document control

Compare all five documents for the same parties, company name, contract date, operating right, challenged termination, takeover event, requested amount, and evidence inventory. Resolve contradictions before delivery.
