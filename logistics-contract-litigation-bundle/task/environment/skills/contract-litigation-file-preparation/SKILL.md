# Contract litigation file preparation

Build the filing set from a single evidence ledger before drafting any document. Read [evidence-ledger.md](references/evidence-ledger.md) to classify each proposition by source, speaker, polarity, time, and permitted use. Read [filing-set-checklist.md](references/filing-set-checklist.md) to propagate the adopted case theory across the complaint, evidence list, handoff record, service form, and refund form.

Keep allegations from an adverse notice as allegations unless another source establishes them. Treat a party's rebuttal as its position rather than proof of every underlying fact. Preserve material uncertainty in fields that need identity, court, signature, or bank information not established by the record.

Draft each requested DOCX as an independent working document. Before delivery, compare the five documents for party names, dates, contract object, requested relief, amount, evidence labels, and the actor responsible for each event.
