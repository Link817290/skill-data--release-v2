# MathML locator guide

Keep a formula's local context: the nearest section heading, the paragraph that introduces it, the formula caption, and the MathML element. For a formula, record operators and variable roles rather than converting it to a prose recipe. A locator should survive a row reorder in the final workbook.

When a formula is repeated on a page, include the caption or the first distinctive variable pair. Do not treat a rendered image URL as the evidence locator. If the source uses a symbol in two limit states, add the state to the ledger key.
