# Hyperkalemia Diagnostic Reasoning

Using only the case materials in `/workspace/materials`, create a reusable, editable Word template for documenting hyperkalemia diagnostic reasoning.

Use the template to complete one separate diagnostic reasoning document for each case. Save the four files as:

- `/workspace/output/hyperkalemia_reasoning_template.docx`
- `/workspace/output/CASE-001_reasoning.docx`
- `/workspace/output/CASE-002_reasoning.docx`
- `/workspace/output/CASE-003_reasoning.docx`

Do not combine the cases into one report.
