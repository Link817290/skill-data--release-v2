# Independent checks before submission

Use a second path that reads the materials, not just formulas copied from the first calculation.

- Reconstruct the eligible line set from the document register. Challenge one superseded record, one late endorsement and one missing quantity/price gate if present.
- Recompute a negative quantity delta and a fractional-quantity extension. Compare sum-of-rounded-lines with round-of-total only to identify the required convention.
- Bridge engineering and material advance balances independently. Test a period where the percentage recovery exceeds the remaining advance.
- Compare the retention base with earned work and with total cash additions; only the defined base is valid.
- Verify opening plus current equals closing for every category, and additions minus deductions equals the requested net.
- Read the application letter against the completed schedules. Check current versus cumulative amount, date cutoff, attachments and unsigned authorization areas.
- Compare repeated amounts in supporting schedules with the adopted summary, not only with a correct final net. A stale retention or recovery amount can survive in an otherwise correct application.
- Accept equivalent wording for the requested payment amount. Look at the meaning and current-period label, including table cells; never select a random matching number from a letter.
- Test that a business-equivalent reordering retains the same result and that changing a real input changes the dependent calculation. A checker that accepts a workbook full of arbitrary constants is not evidence of correctness.

Record actual corrections with their source and affected outputs. If a pass finds no new defect, record that result rather than manufacturing an error to claim another iteration. Distinguish a reference-answer defect, a presentation defect and an evaluator parsing defect.
