# Reading the Framework Figure

The brief says what the screen must establish; the figure says which ratios
measure it. Neither says what any ratio must reach. This reference is about
reasoning to those bars — it deliberately does not carry the numbers, because a
bar you were handed is not a bar you understood.

## Setting the bars

The figure carries no numbers, so each bar is yours to set. That is a real part of
the work, not a gap to route around.

For each ratio, ask what it measures and where its meaning breaks, choose a bar,
**state it in `conventions`**, and hold it constant across every company. Then
check the choice against the pool rather than trusting it:

- A gate that passes almost everyone, or almost no one, is mis-anchored. A bar
  that admits the whole candidate universe is not a gate.
- Move each bar a little and see whether the selection moves with it. If a small
  move swings the list, the list is not a finding yet — say so in the worksheet
  instead of presenting one selection as certain.
- Report the bar you used next to the verdict it produced, so a reader can
  disagree with the bar without re-deriving the arithmetic.

Never leave a gate unapplied because its level is uncertain. An approximately
right bar, applied consistently and disclosed, is far closer to the method than a
gate quietly set to admit everything — and dropping a gate is the single most
expensive mistake available here, because it silently converts a screen into a
list of everything that had data.

### Check each gate's own cut before you deliver

Bars get set one ratio at a time, and their combined effect only becomes visible
at the end. Four gates applied in series compound — each one removes a share of
what reaches it, so the survivors are always a good deal fewer than any single
gate would suggest. That compounding is what makes the final list hard to judge
by feel, and it is why the check below is on the gates rather than on the list.

Check each gate individually:

For each of the four gates, count how many names it admits out of those that
reached it. A gate that admits nearly all of them is not discriminating and its
bar is too loose; a gate that admits almost none is carrying the whole screen
alone and its bar is too tight. Fix the bar at the gate where the problem is,
then let the four compose.

Two failure modes this catches, both of which look reasonable from the inside:

- Every gate set loose. Each name did clear every bar you wrote, so the list feels justified, but most of the pool is on it and it has screened nothing.
- One gate set so tight it eliminates everything. Each rejection is defensible on its own, and the shortlist ends up empty or nearly so — which is not a cautious answer, it is a failure to deliver the judgement that was asked for.

An empty or near-empty shortlist is never the safe option. If your four gates
leave nothing standing, one of the bars is wrong, and the fix is at that bar —
not at the verdicts. Never hand-adjust individual names to make the list look
better: that breaks the "hold it constant across every company" rule and produces
a list nobody can reproduce.

Holding is a separate question and is not a way to avoid deciding. A name is held
when a specific input it needs is missing from the workspace, not when you could
call it and would rather not. Names whose data is complete get a call.

Comparisons are strict. Equality fails.

## Definitions that must be fixed before any bar matters

A bar is meaningless until the quantity under it is pinned down. State each of
these in `conventions` and hold it constant:

- Interest-bearing debt comprises short-term borrowings, the current portion of
  interest-bearing non-current debt, long-term borrowings, bonds payable, and any
  other explicitly interest-bearing item. Lease liabilities are a policy choice:
  state the policy.
- Fixed assets use the **ending** balance, not a period average. Do not mix the
  two conventions between readings.
- Window: the three scored years, with the year before the window as the base for
  the first year's growth.

## The method is read two ways, and they disagree

There is a looser narrative reading and a stricter reading of the same figure.
They differ in three places:

1. Whether the investment-efficiency bar is set loosely or strictly.
2. Whether debt risk is judged on a three-year mean or must hold in every year.
3. Whether a signed profit-quality ratio is kept when net profit is negative, or
   the company is rejected outright for non-positive profit.

Run both readings, report both statuses per company, and keep the disagreement
visible rather than choosing the reading that produces a preferred list. The
method does not resolve them, so neither should the worksheet.

## Arithmetic

All ratios, three-year means and comparisons are computed by you from the
structured statements. There is no calculator: do the arithmetic and own every
conclusion, including the bars you chose.
