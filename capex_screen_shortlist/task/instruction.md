# Capital-expansion screen — this cycle's shortlist

We are looking for companies with the nerve to expand into a weak cycle and
the balance sheet to survive having done it. The pool in
`candidate_universe.csv` is already cut to the sectors we run this screen over —
pharmaceuticals and biotech, electrical equipment, machinery, basic chemicals
and electronics carry most of it, with a tail of autos, defence, appliances,
communications and services. These 60 are what came through.

A name earns a place on the list only if all four hold:

1. it is actually expanding, not merely large;
2. its debt is funding capital expenditure rather than keeping the lights on;
3. that investment is being deployed efficiently;
4. the profit it produces is real.

`methodology/capex-screen-framework.png` is the indicator set we measure those
four with, and how the indicators are grouped. It does not carry the bars — those
are calibrated each cycle, and this cycle they are yours. Choose them, record them
on the Conventions sheet along with the denominator, debt, profit and cash
definitions you used, and hold all of it constant across every name. We have no
cost-of-capital inputs this quarter, so nothing may rest on a discount rate.

Fill in `shortlist_template.xlsx` and save it as `/workspace/shortlist.xlsx`.
Every name in the pool needs exactly one call — the committee gets a list, not a
pair of lists — with the figures you reached it on in the same row. If your
calibration leaves a name genuinely undecidable, say so in the call rather than
forcing it either way.
