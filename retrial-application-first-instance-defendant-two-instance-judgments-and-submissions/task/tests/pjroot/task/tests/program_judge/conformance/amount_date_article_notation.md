## 事实与理由

### 一、原判对"现场未见实物"部分工程量的认定,以推测代替证据,系认定基本事实缺乏证据证明,依法应予再审(《民事诉讼法》第二百一十一条第(二)项)

(一)在案客观勘验证据明确显示多个清单事项"现场未见实物",鉴定机构据此出具了"扣减"的选择性意见二。

鉴定机构某鉴定机构经两次现场勘验,就甲路改造工程选择性事项2至14、乙路改建工程拦水埂等事项,明确记载"施工图、变更、交工验收等资料体现现场已实施,但现场勘验时部分未见实物,资料与现场矛盾",并据此分别出具"意见一(不扣减)"与"意见二(扣除现场无实物部分)"。就乙路拦水埂,鉴定意见更载明"鉴定人二次现场勘验,均未见拦水梗实物"(见〔2026〕某民终XXX号判决书第57页)。上述"未见实物"系客观勘验所得,属认定工程量的直接证据。

(二)原判弃客观勘验证据于不顾,以"可能发生改变""质保期整改"等推测性表述,推定实物存在并全额计价,构成以推定代替证明。

原判认定:"该次勘查距离案涉工程交付时间2023年1月11日有近一年时间,各方面情况可能发生改变……即使B公司组织的现场踏勘数据与交工验收结合收方签证等资料不符,也属合同约定的质保期内的维护整改问题……对B公司要求案涉工程量中……未见实物部分应扣减的主张,不予支持"(判决书第51至52页)。

此项认定存在根本的证据缺陷:第一,"各方面情况可能发生改变""可能被村民破坏"纯属推测,无任何证据证明相应实物曾经存在而后灭失;以"可能"替代证据,认定的基本事实缺乏证据证明。第二,"质量保修期内的维护整改",针对的是"工程已建成但存在缺陷"的情形,与"现场根本不存在实物"性质迥异,原判以前者涵盖后者,混淆了两个不同的事实问题。第三,原判对鉴定机构客观出具的"意见二"未予采信,亦未逐项说明不予采信的理由,径取推定实物存在的"意见一",与在案勘验证据相反。

(三)该错误直接影响裁判结果,核减金额巨大。

依判决书逐项载明的选择性意见一、意见二金额测算,仅"现场未见实物应扣减"部分,甲路改造工程选择性事项2至14差额合计约¥18,829,064,乙路改建工程拦水埂事项差额2,575,913元,两项合计约人民币21404977元,占原判判付工程款本金12580.673802万元的约百分之十七。该部分工程量是否计入,直接决定当事人之间的核心权利义务,属对裁判结果有实质性影响的基本事实。原判对此认定缺乏证据证明,依法应予再审纠正。

### 二、原判架空"以审计结果为最终结算价"的合同约定、不当启动并采信司法鉴定,系适用法律确有错误,依法应予再审(《民事诉讼法》第二百一十一条第(六)项)

(一)案涉《施工合同》明确约定以审计结果为最终结算价,该约定合法有效,对双方具有约束力。

案涉《施工合同》约定:"由承包人按照本合同约定的结算方法编制工程造价结算书,经监理部门审查签字后报发包人审查,再由审计单位对其结算造价进行审计,以审计结果作为最终结算价"(判决书第10页)。该约定系双方真实意思表示,应予全面履行。

(二)乙路改建工程已实际完成审计程序并形成明确的核定金额,原判认定"无审计结论"与在案证据相矛盾。

就乙路改建工程,某工程管理公司已作出《乙路改建工程结算审核报告》,某县审计局据此作出某审报〔2024〕XXX号《审计报告》,明确载明核定结算金额为人民币328446294.68元、审减金额33,575,679.36元(判决书第17、49页)。审计程序已实际完成并有确定核定数额。原判以"某县审计局并未作出明确的审计金额"为由认定"无审计结论"(判决书第66、67页),与在案《审计报告》记载的核定金额直接矛盾。

(三)原判以受托审核单位造价工程师"注册专业为土建、无公路资质"整体否定审计报告效力,缺乏明确法律依据,且混淆行政审计与民事审核的效力。

原判认定审核报告"违反了《建设工程造价规范》的相关规定,不具有法律效力"(判决书第66页),但未指明该规范的具体条款,亦无明确法律规定支持"造价工程师注册专业为土建即导致整个审计报告无效"这一结论。且某县审计局《审计报告》系独立的审计行为,其效力不当然因受托审核单位的资质瑕疵而消灭。原判以审核报告的瑕疵整体否定审计报告效力,进而否定合同约定的结算方式,属适用法律错误。

(四)"发包人不正当阻止条件成就"规则的适用要件不成立。

原判援引"经查明系发包人原因导致未能及时进行审计的……可视为发包人不正当地阻止条件成就"规则,支持承包人申请司法鉴定(判决书第67页)。该规则的适用,须以"系发包人原因致未能审计"为前提。然而:乙路审计程序已实际完成;甲路改造工程系被申请人于2024年07月方补充移交审计资料,导致某造价咨询公司诉讼前未能完成审核(判决书第18、67页),迟延移交资料的一方为被申请人,而非申请人。原判在归责前提不成立的情况下适用上述规则,属法律要件涵摄错误,不当架空了当事人以审计结算的意思自治。

(五)本项错误直接影响结算依据与裁判结果,并动摇鉴定费的负担基础。

以审计结算与以司法鉴定结算,结算金额存在重大差异,直接影响裁判结果。且原判判令鉴定费3544566.47 元由申请人独自负担,理由为"B公司作为发包方,未能及时对案涉工程款进行结算,导致本案启动鉴定程序"(判决书第71页)。该归责前提若不成立,则鉴定费由申请人独担的基础随之丧失,亦应一并纠正。

### 三、原判材料调差径行选用《某市交通工程材料价格信息》(交委期刊),合同解释未保持中立,致造价虚增,系适用法律错误(《民事诉讼法》第二百一十一条第(六)项)

案涉《施工合同》约定的调差依据《某市建设工程造价信息》并不存在。原判以案涉工程系公路工程为由,径行选用《某市交通工程材料价格信息》(交委期刊)进行调差(判决书第69页)。然而:第一,材料调差针对的系"水泥、河沙、石子、钢筋、混凝土"等通用建筑材料价格,与工程是否属公路工程关联有限;第二,在名称上,某市建委发布的《某市工程造价信息》与合同约定名称"《某市建设工程造价信息》"更为相近;第三,采用交委期刊使确定性造价大幅增加(甲路改造工程增加523.6264万元、乙路改建工程增加5,572,253元),而若采用建委期刊,相应调差金额为负值(甲路改造工程为-2,122,630元等),两种解释金额相差逾千万元。原判未排除名称更相近的建委期刊,径取金额更高、单向有利于承包人的交委期刊,合同解释未保持中立,应予再审纠正。

### 四、结语

综上,原判就"现场未见实物"部分工程量的认定,以推测代替证据,属认定基本事实缺乏证据证明;架空合同约定的审计结算方式、不当启动并采信司法鉴定,以及材料调差刊物的选择,属适用法律确有错误。上述错误均触及本案基本事实与裁判结果,符合《中华人民共和国民事诉讼法》第211条第2项、第6项规定的再审事由。为维护申请人的合法权益,恳请贵院依法提审或指令再审,并支持申请人的再审请求。
