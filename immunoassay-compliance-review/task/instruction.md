# Immunoassay batch compliance review

Our quality unit needs the compliance review written up for this immunoassay
run series. Everything the reviewers recorded is in `03_原始材料.xlsx` — the
workbook is the record of what happened, so leave it exactly as it is and work
from a copy of the report template.

Check what reference guidance you have before opening the workbook.

Copy `/workspace/templates/review_report_template.md` to
`/workspace/output/review_report.md` and complete it item by item in Simplified
Chinese, keeping the template's structure. Every result you state has to be
traceable to the workbook; cite the sheet and cell that carries it.

Where the workbook cannot settle an item, mark it `PENDING` and say in one line
what is missing. An honest `PENDING` is worth more to the reviewer than a
plausible number nobody can trace.
The formal analytical-run inventory covers Run19 through Run54. Run1 is a
separate system-suitability/comparator record: it may be reported as supporting
evidence, but it is not one of the 36 formal run dispositions.
