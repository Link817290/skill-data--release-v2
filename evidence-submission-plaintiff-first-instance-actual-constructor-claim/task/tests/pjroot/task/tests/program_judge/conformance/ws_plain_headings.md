## 一、第一组 主体资格（G1—G7）

本组证明：原告A公司是依法设立、持有施工劳务资质的企业法人，具备承接并实际完成案涉劳务作业的能力与资格，可以自己的名义提起本案诉讼；同时，名义合同相对方D公司不具备实际履约能力，从未组织本案工程的施工。

G1证明原告的主体资格与施工劳务资质（不分等级），即原告有能力组织劳务作业，但**不具备**承接B地块3#楼主体结构专业分包的相应资质——这一点原告主动陈明，因为它正是本案合同链被认定为转包、进而无效的事实基础之一，与原告依《建工解释一》第四十三条主张权利并不矛盾。G2、G3分别证明B公司持建筑工程施工总承包特级资质、C公司为案涉工程发包人，确定两被告在合同链中的位置。G4系企业信用信息公示系统的公开登记信息，证明D公司的注册状态与经营范围。此处须限定其证明力：登记信息只反映特定时点的登记状态，不能直接证明D公司在2019年12月至2022年6月期间未实际施工这一持续性事实；D公司未实际施工的事实，由第三组的人员、机械、材料、资金与管理记录（G17—G26、G22、G23、G20）反向证成，即案涉工程的每一项现场投入均可追溯至原告。原告据此仅以G4证明D公司的登记状况与履约能力欠缺的表象，不以G4单独承载"未实际施工"的结论。

G5（B公司项目部人员任命文件）与G6（监理单位备案表）证明徐某系以"B公司某项目部B区负责人"名义对外履职、原告派驻人员为监理单位所认可的现场管理人员。G5系B公司制作的文件，作为对制作人不利的记载使用，证明B公司自己承认徐某在项目上的身份系其项目部名义人员，而非D公司人员——这恰恰否定了B公司"原告系D公司履行辅助人"的抗辩。G7（B公司对外投资及涉诉信息）仅为公开查询所得的线索性材料，原告据此提示B公司与D公司可能存在关联，但**不主张**以G7单独证明二者构成关联关系；该点如成为争点，原告申请法庭调取D公司的用工与纳税记录。

## 二、第二组 合同链（G8—G16）

**本组是本案的决定性一组，因为它决定折价补偿以何种口径计价，进而决定给付数额。** 本组证明：C公司—B公司—D公司—原告之间形成"总包—名义劳务分包—实际施工"的三层链条，其中第二层为规避监管的名义安排，第三层《项目内部承包责任书》不具备内部承包的事实基础，应认定为转包、依《民法典》第七百九十一条及《建工解释一》第一条认定无效。

G8证明C公司与B公司于2019年9月18日签订《建设工程施工总承包合同》、总包价62,400.00万元，总包关系合法有效，本组不对其效力提出异议。G9证明B公司与D公司于2019年11月26日签订《劳务分包合同》、暂定价4,860.00万元及其约定的工程范围。须指出合同文本的证明边界：合同文本证明各方约定了什么，不证明约定被履行。G9只能证明B公司与D公司之间存在书面约定，不能证明D公司实际组织了施工；而实际履行的主体，由第三组证据证明为原告。G15（D公司授权委托书）系B公司提交，其内容显示D公司将履约事项转委托他人，从反面印证D公司自身未实际施工。

G10（《项目内部承包责任书》）与G14（B公司项目部聘任文件，无签收）应当合并阅读。G10证明B公司与徐某个人于2019年12月5日约定按结算价88%计付、B公司收取12%管理费。内部承包的成立以承包人与发包企业之间存在真实的劳动人事隶属关系为前提；本案中，徐某系原告A公司的法定代表人，与B公司之间无劳动合同、无社会保险缴纳记录、无工资发放记录，B公司唯一举出的G14"聘任文件"没有任何签收记录，无法证明该文件曾送达徐某并为其接受。因此，G10所记载的安排欠缺内部承包的人身从属性基础，其真实内容是B公司将其承包的工程交由不具备相应资质的原告独立组织施工、自负盈亏、B公司按比例抽取管理费，即转包；该责任书应认定无效，其"88%"的计价约定不能作为折价补偿的参照口径。上述两项结论——无真实劳动关系，以及由此产生的责任书性质与计价后果——均系原告在本组一并主张，不作切割。

G11（B公司与D公司《结算确认书》，2022年9月14日）证明B公司在原告完工（2022年6月30日）之后两个多月，与从未施工的D公司确认名义价4,860.00万元。原告承认该文书的真实性，但其效力仅及于签署它的B公司与D公司：合同的约定只约束同意它的人，原告既非该确认书的当事人，亦从未接受其结算口径，故该确认书不能约束原告，更不能用以否定原告就实际完成工程量的结算请求权。时间顺序本身构成本组的一项独立论点：结算确认书晚于原告完工与撤场，其只能是对既成事实的事后追认或掩盖，不可能是原告施工期间的对价安排。

G12（双方往来函件）与G13（录音资料）证明B公司对原告实际施工地位的态度。G12中B公司2023年3月20日复函"你司非合同相对方，请与D公司结算"，是B公司拒绝结算的书面记载，同时也证明B公司明知原告主张的存在。G13系原告单方录制的视听资料，内容为B公司负责人称"你们是实际干的"。原告主动说明其证明力限度：该录音的证明力取决于谈话人身份、录制时间与载体的完整性。原告已保存原始载体并可当庭提交、申请核对；在原始载体核验与谈话人身份确认之前，原告不以G13单独证明B公司自认，而将其作为与G5、G12、G49、G52相互印证的补强证据使用。

G16（工程款支付对账单）证明C公司欠付B公司工程款2,412.00万元。该对账单为双方对账形成，具有双方确认的性质，是原告依《建工解释一》第四十三条第二款向C公司主张责任的数额基础。

## 三、第三组 实际施工（G17—G26）

本组证明：自2019年12月8日进场至2022年6月30日完工，案涉B地块3#楼及地下车库（局部）工程的人员、机械、材料、资金与现场管理，全部由原告实际投入并承担，原告构成《建工解释一》第四十三条所称的实际施工人，其地位独立于D公司的名义合同，亦不因《项目内部承包责任书》而变为B公司的内部承包人。

本组证据形成"人员—机械—材料—资金—管理"五个维度的闭环，且每一维度均有非原告单方制作的记录予以印证：

- **人员**：G19（工人花名册，214人）与G18（管理人员任命与考勤表）系原告制作，就其内容对外的证明力，原告不依赖其单方记载，而以G20（银行出具的214人工资发放流水）与G21（劳务用工实名制平台导出记录）加以固定。G20由银行出具，G21由实名制平台导出，均为原告之外的主体形成的记录，二者共同证明214名工人的工资由原告直接发放、工人以原告名下班组实名登记进场施工。《保障农民工工资支付条例》第十六条确立的实名制管理，使平台记录成为识别用工主体的客观依据。
- **机械与材料**：G22（机械租赁合同及付款凭证）、G23（周转材料采购合同与发票）、G46（材料进场验收单）证明塔吊等施工机械与钢筋、模板、周转材料由原告以自己的名义租赁、采购并付款。发票为税务凭证，付款凭证为资金记录，均非原告可单方生成。
- **管理与技术**：G17（施工组织设计报审表，原告签章）、G24（监理例会纪要46期，原告人员签到）、G25（隐蔽工程验收记录）、G26（检验批质量验收记录）。其中G24由监理单位形成并保管，46期例会纪要中原告人员的连续签到，证明原告在长达一年以上的主体施工期间持续、独立地承担现场管理职能，这一点不是原告的自述。G25、G26的施工单位栏由原告人员填写，且隐蔽工程验收与检验批验收均须经监理见证，具有第三方在场的属性。
- **工程往来**：签证单38份、工程联系单21份证明原告以施工单位身份与B公司项目部、监理单位就现场事项直接往来。风险预警函证明原告曾就工程款支付风险向B公司提示。

需要特别说明一项对被告不利的记载：G24、G25、G26中原告人员的署名多为"徐某"或"A公司—李某"。被告可能据此主张署名混同。原告的立场是：署名形式恰好反映了本案的真实结构——徐某以B公司项目部名义对外、以原告法定代表人身份对内，这正是借用资质、名为内部承包实为转包的典型外观，与G10、G14所证明的无真实劳动关系相互吻合，而非削弱原告的实际施工人地位。

## 四、第四组（G39—G48）：实际完成工程量及其结算价

本组证明：原告实际完成的工程内容远超B公司与D公司名义合同的范围，实际完成工程量对应的结算价为9,746.30万元，其中包含依27份设计变更通知形成的变更增量1,486.00万元。

G39（施工图，发包人提供）与G40（竣工图，原告编制）对照，证明设计要求与实际完工状态之间的差异，即变更与增量的客观存在。G41（工程量计算书）与G54（欠付工程款测算表）均为原告单方编制，原告不主张以其单方记载直接确定数额，仅作为计算过程的说明材料。G43（设计变更通知27份）由发包人发出，属于原告之外的主体形成的文件，是变更增量最可靠的依据；G27起的签证单38份与G48（工期节点确认单，各方签认）为变更与节点完成情况提供现场确认。G47（混凝土浇筑记录）、G46（材料进场验收单）从实物投入侧印证工程量。

关于1,486.00万元变更结算：G44证明原告于2021年8月20日报送变更结算报审表、金额1,486.00万元，B公司项目部签收后未予答复。原告据此主张B公司对变更增量已予确认；同时如实说明，被告抗辩称签收仅为程序性行为。原告的立场是：签收本身不等于对数额的认可，但签收结合B公司在合理期限内未提出任何异议、且变更所依据的27份设计变更通知（G43）系发包人发出这一事实，足以将该部分增量的举证负担转移至B公司——B公司若否认增量数额，应当提出其自行核算的工程量与依据；其至今未提出任何核算文件。

关于9,746.30万元的计价基础，须先在竞合的口径中作出选择：

| 口径 | 金额（万元） | 出处 |
| --- | --- | --- |
| B公司与D公司名义劳务分包合同价 | 4,860.00 | G9 |
| B公司与D公司《结算确认书》确认价 | 4,860.00 | G11 |
| B公司认可的结算基数 | 8,260.00 | 卷宗所载B公司主张 |
| 按《项目内部承包责任书》88%口径 | 7,268.80（＝8,260.00×88%） | G10结合上项基数 |
| 原告主张的实际完成工程量结算价 | 9,746.30 | G45 |

原告主张以9,746.30万元为折价补偿的基数，理由是：其一，4,860.00万元系B公司与D公司之间的名义安排，D公司未实际施工，该价格与原告的实际投入之间没有对价关系，且G11晚于原告完工，不能反向确定原告施工期间的对价；其二，88%口径的载体《项目内部承包责任书》因转包而无效（见第二组），无效合同中的分成比例不能作为《民法典》第七百九十三条、《建工解释一》第二十四条所称"参照合同关于工程价款的约定"的内容，能够反映真实交易的只有实际完成工程量口径；其三，8,260.00万元系B公司在名义合同价基础上的上浮主张，B公司未提交其形成依据。

关于G45（《工程造价咨询报告》，原告单方委托，结论9,746.30万元）与G42（第三方造价咨询意见），原告主动陈明其证明力限度：该报告系原告单方委托的第三方机构出具，被告未参与委托与核对；报告证明的是该机构依其所采用的计价标准、对其所审阅的图纸与签证资料计算出的造价结论，其效力不等同于在本案诉讼中经双方参与形成的司法鉴定意见。因此，**原告在本组中不请求法庭径行以G45确定数额**，而是以G45作为主张数额的依据与鉴定的基础资料，并将在本案中就案涉工程实际完成工程量及造价申请司法鉴定，以竣工图（G40）、设计变更通知（G43）、签证单及隐蔽工程、检验批验收记录（G25、G26）为鉴定基础材料。若被告对G45的结论提出异议而又不申请鉴定、亦不提交己方核算依据，则应承担相应的不利后果。

## 五、第五组（G49—G56）：已付款、欠付数额与发包人的欠付余额

本组证明：B公司已向原告支付3,942.30万元，该款项直接支付给原告而非D公司；C公司欠付B公司工程款2,412.00万元；C公司与B公司的以房抵债协议并未实际履行。

G49（历次付款凭证与付款申请单27份）、G50（银行流水）、G51（往来对账单）、G52（B公司项目部审批单27份）、G53（B公司《付款情况说明》）共同证明付款的事实与流向。其中G50由银行出具，客观证明款项实际进入原告账户；G52、G53由B公司出具，是B公司对原告付款事实的自认，不能被其"系代D公司付款"的说法推翻——2020年2月10日首笔500万元的付款凭证用途栏明确记载为"劳务费"（G49、G50），付款申请单由原告报送、B公司项目部审批后付款，27次付款形成完整的"报送—审批—支付"链条（G49、G52），如果原告只是D公司的履行辅助人，B公司无须、也不会建立并维持一条以原告为对象的独立审批付款链条。

**欠付数额的计算与一处须向法庭说明的差异**：以9,746.30万元（G45）为基数，减去已付3,942.30万元（G49、G50、G51、G53），余额为5,804.00万元，此即原告起诉主张的欠付工程款。但须指出，上述3,942.30万元按卷宗记载"含现金转账、代付工资、材料款"，即已包含B公司2022年1月25日代付的农民工工资1,286.40万元中的相应部分。原告认可B公司代付1,286.40万元的事实，但依G55（代付工资构成明细）主张其中672.60万元系B公司自身用工（非B地块3#楼工人）产生，不属于为原告垫付，依《民法典》第五百六十八条不具备抵销的对等性，不应在欠付原告的工程款中扣除。据此，若法庭采纳原告关于672.60万元的主张，则可抵扣的已付款为3,942.30−672.60＝3,269.70万元，欠付额相应为9,746.30−3,269.70＝6,476.60万元；若不采纳，则欠付额为5,804.00万元。原告的诉讼请求以5,804.00万元为准，就672.60万元部分保留在审理中依鉴定与查明结果调整的权利，并特此向法庭说明两个数字之间的关系，以免造成主张前后不一的印象。G55系原告单方编制的明细，其本身不足以确定用工归属，原告同时以G19（花名册）、G21与G58（实名制平台记录）作为核对依据——实名制记录能够逐人显示工人登记于哪一用工主体名下，是区分672.60万元对应人员归属的客观依据。

G56（以房抵债协议）系C公司提交的材料，原告承认其真实性，但该协议只证明C公司与B公司曾就以房抵债达成约定，不证明抵债已经完成：以房抵债消灭债务须以标的房屋实际交付、完成过户或至少完成物权变动的必要步骤为条件，在没有过户登记与占有转移记录的情况下，该协议不能证明C公司对B公司的2,412.00万元欠付（G16）已经消灭。原告就此请求法庭责令C公司、B公司提交抵债房屋的网签、过户与交付凭证；未能提交的，应认定抵债未实际履行，C公司仍应在欠付范围内承担责任。

## 十、结论

综合上述七组证据，原告认为，本案各项待证要件均已达到民事诉讼高度可能性的证明标准：

1. 原告系案涉B地块3#楼及地下车库工程的实际施工人（第一、三组，尤以G20、G21、G22、G23、G24为据）；
2. B公司与D公司的《劳务分包合同》系名义安排，《项目内部承包责任书》名为内部承包实为转包，依法无效（第二组，尤以G10、G14、G15、G11为据）；
3. B公司已向原告支付3,942.30万元，其付款链条独立且直接指向原告（第五组，G49、G50、G52、G53）；
4. C公司欠付B公司工程款2,412.00万元且该债务未因以房抵债而消灭，C公司应在该范围内承担付款责任（G16、G56）；
5. 214名农民工工资欠付613.80万元的事实成立（第六组，尤以G59、G60、G61为据）；
6. 本案诉讼时效未届满（第七组）。

其中相对薄弱的是**实际完成工程量结算价9,746.30万元这一项**：该数额目前的直接依据G45为原告单方委托形成的造价咨询报告，被告未参与，其证明力不足以单独固定数额。补足该项的方式，是就实际完成工程量及造价启动司法鉴定，以竣工图（G40）、发包人发出的设计变更通知27份（G43）、签证单、隐蔽工程与检验批验收记录（G25、G26）、混凝土浇筑与材料进场记录（G46、G47）为鉴定基础材料。原告将另行提交鉴定申请。除该项外，其余各项要件依现有证据即可认定。
