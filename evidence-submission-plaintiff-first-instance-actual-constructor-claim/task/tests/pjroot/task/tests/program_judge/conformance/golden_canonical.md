一、举证总述
根据《中华人民共和国民事诉讼法》第六十七条及《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第九十条、第九十一条之规定，当事人对自己提出的诉讼请求所依据的事实或者反驳对方诉讼请求所依据的事实，应当提供证据加以证明。原告A公司（以下简称"原告"）就其与被告一B公司（以下简称"B公司"）、被告二C公司（以下简称"C公司"）建设工程施工合同纠纷一案，围绕"实际施工人身份—合同无效—实际完成工程量—欠付金额—发包人责任范围—农民工工资"的证明主线，系统举出七组证据，编号G1至G68，力求形成完整、闭合的证明体系。
本举证体系的逻辑链条为：第一组证据锁定各方主体资格及关联关系，为后续权利义务认定奠定前提；第二组证据揭示"总包—名义劳务分包—实际施工"的合同链条及内部承包责任书实为转包的法律性质；第三组证据以海量客观履约记录锁定原告实际施工人身份，系本案最核心的事实基础；第四组证据证明原告实际完成的工程量及造价9,746.30万元；第五组证据证明已付款3,942.30万元及欠付事实；第六组证据证明农民工工资欠付613.80万元；第七组证据证明时效中断与持续催告。七组证据相互印证，足以支持原告的全部诉讼请求。

三、证据之间的关联性与证明体系
本案七组证据并非孤立存在，而是层层递进、相互印证的有机整体。第一组确立主体，第二组揭示合同性质，第三组以海量履约记录锁定实际施工人身份——此组为全案基石，其后各组均依附于该身份认定。第四组在第三组身份基础上计量实际工程量，第五组在工程量基础上核算已付款与欠付，第六组从农民工权益维度强化社会事实，第七组从程序维度补强请求权合法性。特别地，第三组中工资发放流水（G20）、实名制平台记录（G21）与第六组工资表（G57）、考勤（G58）形成人员维度的交叉印证；第三组签证单（G27—G64）与第四组设计变更通知（G43）、变更结算报审表（G44）形成工程量维度的交叉印证；第二组对账单（G16）与第五组以房抵债协议（G56）形成发包人责任维度的交叉印证。全案证据环环相扣，构成无可辩驳的证明体系。
四、举证责任的说明与转移
依据《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第九十条、第一百零八条，原告已就实际施工人身份、合同无效、实际完成工程量、欠付金额、发包人欠付范围及农民工工资等要件事实完成初步举证，达到高度盖然性证明标准。尤其是第三组证据对实际施工人身份的锁定，已使待证事实处于"真实存在的可能性明显大于不存在"的状态。
被告B公司若主张内部承包有效、管理费应予扣减、代付工资应全额抵扣、质量存在缺陷，或被告C公司若主张以房抵债已消灭欠付债务，则上述抗辩均属积极事实主张，举证责任应转移至二被告。原告已完成己方举证义务，恳请法庭在被告未能反证时，对其抗辩不予采纳，并依法采纳原告所举证据。
五、请求事项
综上，原告恳请法庭：
一、依法组织质证，对前述七组共六十八项证据予以采信；
