## 一、举证总纲

原告A公司依据《中华人民共和国民事诉讼法》第六十七条、《最高人民法院关于民事诉讼证据的若干规定》第一条、第五十条之规定，于举证期限内向贵院提交证据共**七组**，拟证明以下四项基本事实与法律评价：

1. **主体事实**——原告系案涉"某项目"B地块3#楼及地下车库工程的**实际施工人**：原告独立组织人员、机械、材料进场，独立发放全部作业人员工资，独立承担施工全过程的技术、质量、安全管理，其投入具有独立性与完整性，并非第三人D公司的履行辅助人，亦非徐某个人内部承包的执行工具。
2. **效力事实**——B公司与D公司的《劳务分包合同》系规避监管的**名义合同**，B公司与徐某的《项目内部承包责任书》系**名为内部承包、实为转包**。依《民法典》第七百九十一条、《建工解释一》第一条，上述安排无效，B公司不得据以对抗原告的结算请求。
3. **数额事实**——工程已于2022年6月30日完工且质量合格，原告按实际完成工程量（含27项设计变更与38份签证增量）的结算价为**9,746.30万元**，B公司已付**3,942.30万元**，尚欠**5,804.00万元**；其中涉及214名农民工工资欠付**613.80万元**。12%管理费991.20万元及B公司自身用工部分的代付工资672.60万元均不应扣减。
4. **责任范围事实**——发包人C公司经对账尚欠B公司工程款**2,412.00万元**，其主张的"以房抵债"并未实际履行，债务未消灭。依《建工解释一》第四十三条第二款，C公司应在该欠付范围内对原告承担付款责任。

**举证策略说明：** 本案胜负不在于单份书证，而在于**证据链的闭合**。原告举证以"投入链—履约链—审批链—资金链"四条链条相互锁定：原告投入（G17—G26、G46、G47）→ 原告履约并经监理与被告项目部签认（G24、G25、G48、签证与工程联系单）→ 被告项目部逐笔审批原告付款申请（G49、G52）→ 款项实际支付至原告账户且用途载明"劳务费"（G5、G50）。四链闭合后，D公司名义合同与"内部承包"抗辩在事实层面均无落脚点。

**关于证据编号的说明：** 卷宗底档中第三组"签证单38份"与"工程联系单21份"曾使用G27—G64、G65—G85编号，与第四至第七组G39—G68编号存在重叠。为避免庭审混乱，原告在正式提交时对该两项证据改按**G27-1至G27-38**、**G28-1至G28-21**子号编列，其余编号沿用G1—G68不变。特此向法庭与对方当事人释明。

本组回应争议焦点五、六。

**其一，资金链直指原告。** G49、G50、G52形成"原告报送申请—B公司项目部审批—B公司账户付款至原告账户"的完整闭环，共27笔、累计3,942.30万元，历时近两年。B公司辩称系"代D公司付款"，但代付须有委托基础与代付意思表示，B公司未举出D公司的任何付款指令；而首笔500万元付款凭证用途栏载明"**劳务费**"，直接指向原告的劳务提供者身份。经济上，一方持续两年向另一方直接支付近四千万元，同时否认与其存在任何权利义务关系，不合常理。

**其二，代付工资的抵扣应以用工归属为界。** 原告不否认B公司于2022-01-25代付1,286.40万元的事实，认可其中**613.80万元**对应原告所招用214名工人的欠薪，同意在工程款中抵扣。但其中**672.60万元**依G55及第六组G57、G58的实名制记录与工资表比对，对应人员并不在原告的214人花名册之内，系B公司自身用工或其他分包单位用工所生，与原告无关，不得计入原告已收款。请求法庭以**实名制平台记录（G58）与原告工资表（G57）的逐人比对结果**作为划分标准，该标准客观可验，不依赖任何一方陈述。

**其三，以房抵债未履行则债务不消灭。** G56系C公司提供的反证材料，原告主动提交并申请法庭审查其履行情况。以房抵债属新债清偿，在房屋未实际交付、未办理过户登记之前，旧债不消灭。原告已就此提出调查取证申请（见第五部分），请求调取抵债房屋的网签备案与不动产登记信息。在C公司未能证明抵债已实际履行的情况下，G16所载2,412.00万元欠付应予认定。

关联争点：争议焦点五、六。
