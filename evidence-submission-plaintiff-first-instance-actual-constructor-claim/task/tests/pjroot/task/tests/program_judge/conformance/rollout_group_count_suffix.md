## 一、总体举证思路

本案的裁判路径可归结为三个递进问题：**谁实际干了工程（主体）→ 依何种口径计价（计价）→ 由谁在多大范围内付款（责任）**。原告的举证据此按"事实—性质—数额—责任"四层展开：

1. **锁定实际施工人身份。** 以"人员—机械—材料—资金—管理"五位一体的过程性证据（第三组）形成闭环，证明B地块3#楼及地下车库的全部施工投入均由原告完成，D公司未有任何实际履约行为，原告构成《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》（以下简称《建工解释一》）第四十三条所称实际施工人。
2. **击穿"内部承包"抗辩。** 内部承包的成立前提是承包人与企业之间存在真实的劳动人事隶属关系。原告以B公司举证结构上的空白（无劳动合同、无社保、无工资发放、聘任文件无签收）结合徐某系原告法定代表人的身份事实，证明《项目内部承包责任书》名为内部承包、实为转包，依《民法典》第七百九十一条、第一百五十三条及《建工解释一》第一条应认定无效。
3. **确立实际完成工程量的计价口径。** 合同无效而工程质量合格的，依《民法典》第七百九十三条、《建工解释一》第二十四条参照"合同关于工程价款的约定"折价补偿；被参照的应是反映真实交易的实际施工口径，而非无效文书中的88%让利条款。原告以竣工图、工程量计算书、27份设计变更、38份签证单及第三方造价报告支撑9,746.30万元的结算价，并申请造价司法鉴定予以固化。
4. **穿透发包人责任并处理抵扣。** 以对账单证明C公司欠付B公司工程款2,412.00万元，以《以房抵债协议》未实际履行（未过户、未交付占有）阻却C公司的债务消灭抗辩；以代付工资构成明细证明1,286.40万元中的672.60万元系B公司自身用工，不在抵扣范围。

## 四、对被告方举证的质证预判

1. **对B公司"内部承包"举证的质证要点：** 要求其提交徐某的劳动合同、社保缴纳记录、工资发放流水、绩效考核文件。上述材料缺一，内部承包即欠缺事实基础；仅凭无签收的聘任文件（G14），不能达到高度盖然性的证明标准。
2. **对《结算确认书》的质证要点：** 形式上真实但内容不具对抗力——签订于原告撤场之后、由不承担施工的两方作出、金额恰好等于名义暂定价而未反映27份设计变更，明显不符合客观工程事实。
3. **对12%管理费的质证要点：** 要求B公司举证其实际提供的管理服务内容与对应成本（管理人员名单、社保、现场记录）。B公司项目部人员实为徐某所派（G5、G18），现场管理由原告承担（G17、G24），管理费缺乏对价，且系基于无效合同产生，不应在折价补偿中扣减；举证不能的部分应不予支持。
4. **对单方质量检测报告的质证要点：** 该报告系B公司单方委托，取样、见证程序未经原告参与，依《证据规定》第四十一条不足以推翻已完工验收的事实。若被告坚持质量抗辩，应由其依法申请质量司法鉴定并预交费用；在鉴定结论作出前，不得据此扣减工程款。工程已于2022年6月30日实体完工并经组织验收，G26、G40、G48可资佐证。
5. **对以房抵债协议的质证要点：** 审查抵债房产是否办理过户登记、是否实际交付占有、是否存在查封或抵押。未实际履行的以房抵债不产生清偿效果，C公司的欠付债务并未消灭。
