# Event Evidence and Chronology

## Different records answer different questions

A schedule records an intended assignment. Its version metadata establishes when that intention became an available record. A notification or employee acknowledgment supplies a different fact: whether the person received the arrangement. Keep these facts distinct even if a system displays them together.

Attendance or access control records establish recorded presence. They do not, by themselves, establish the activity, who required it or the payable duration. Look for a contemporaneous assignment, handover, task record or attributable supervisor confirmation. Record the extent and limits of each source rather than treating a single source as infallible.

A leave ledger records the requested or registered arrangement. Approval timestamps, employee acknowledgment, matching person and duration, and the actual activity on the proposed leave date address different prerequisites. A payroll state records what the payroll process did; it cannot substitute for these facts.

## A practical working table

For each event keep: stable object key; original and effective schedule; version and publication time; initiating party; notification evidence; actual activity and interval; proposed leave period; request and approval times; acceptance evidence; leave-date activity; payroll record; unresolved contradictions; conclusion; and citations.

This working table is for analysis. The final workbook can use a different arrangement if it communicates the same relations clearly.

## Joining without creating facts

Use an explicit event identifier when available. When joining attendance by employee and date, preserve the actual matched rows. A date containing several visits requires activity-level reconciliation. A different employee's visit is not evidence for the subject event. Check whether the chosen record concerns the original work date or the later leave date.

Do not replace a missing approval with the date shown in another system. Do not infer employee agreement from a salary slip acknowledgment unless the policy and that acknowledgment actually establish agreement to the leave arrangement.

## Handling conflicting observations

Write the proposition each source supports. Identify whether the disagreement is about timing, actor, activity, amount or status. Decide which policy prerequisites remain established and which remain unresolved. Specify the smallest additional record that would settle the disagreement. Preserve contradictory source records in the citation chain rather than silently selecting the convenient one.
