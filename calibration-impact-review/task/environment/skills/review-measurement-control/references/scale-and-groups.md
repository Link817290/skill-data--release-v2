# Scale and grouped checks

Write the forward calibration equation and units before inverting it. For response y = a + b x, infer x from (y-a)/b. Name the sign convention of the reported discrepancy; a correction and an error can have opposite signs. Convert the residual uncertainty to the same scale as the discrepancy before applying a threshold.

A procedure may control a group of reference points rather than independent pointwise decisions. Derive the critical probability from the declared family error rule; do not replace it with a familiar single-point interval. Keep full precision until the final comparison and state whether equality is accepted.

A failing reference point can invalidate an entire run or period only when the procedure establishes that scope. Passing checks later do not establish that earlier workload items were repeated or repaired. A descriptive shift in many individually passing values warrants process review, without proving a particular physical failure mode.
