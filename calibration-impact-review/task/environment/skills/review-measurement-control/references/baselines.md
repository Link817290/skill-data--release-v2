# Baseline discipline

Freeze a baseline by the approved membership rule before examining monitoring outcomes. Use an explicit record identifier: repeated timestamps can represent distinct runs. Reconcile observed membership with legacy counts and degrees of freedom. An unexplained count difference is not proof that specific records were lost.

Pool residual variances using their degrees of freedom, then take the square root. Averaging standard deviations is different. The denominator degrees of freedom comes from the actual accepted baseline, not an unrelated summary card. A variance-control limit is generally one-sided; a signed bias limit can be two-sided.

Do not silently include monitoring data or discard baseline outliers to make a chart pass. If the baseline itself has questionable records, retain the prescribed calculation, identify the concern and distinguish a formally approved replacement baseline from an exploratory sensitivity check.

Useful checks: reorder source rows; retain different records with the same timestamp; recompute on changed values; test unequal residual degrees of freedom; compare fixed-baseline and all-data limits. Label derived probes as probes, not original-data failures.
