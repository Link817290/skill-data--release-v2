# Rerunnable measurement checks

A reusable tool must read the current records and settings rather than replay a previously verified answer. Separate parsing, parameter validation, calculations and serialization so each stage can be challenged independently.

Treat a configured method name as an executable contract. Reject unsupported selectors explicitly; silently falling back to the only implemented method can return convincing numbers under an incorrect declared procedure. Validate domain constraints and group completeness before writing success artifacts.

Use metamorphic checks to test dependence on the evidence: reorder rows and columns, rename record IDs, move files to paths containing spaces, change a baseline observation, introduce a new monitoring exception and alter a calibration coefficient. Invariance under representation changes and appropriate changes under substantive inputs are different obligations. Reconstruct the expected results independently for changed inputs.

Keep record-level failures, failing metrics and affected groups separate. One record may fail two metrics; several failed references may identify one affected period. Unknown downstream workload stays unknown until complete linkage evidence is supplied. Direct CLI tests are implementation validation, not evidence of model improvement.

Probe small, valid tail probabilities. Forming `1-alpha` or subtracting two nearly equal probabilities can round a finite tail to zero before quantile inversion. Use stable complement/inverse-survival formulations and `log1p`/`expm1` for grouped probabilities. Cross-check with a different numerical route, such as solving the log-survival equation; merely calling a similarly implemented inverse in a second script may repeat the same defect.

Before pooling records, validate the identity of the measured system, reference standard and method/design. Either calculate independently for each supported group or explicitly reject mixed groups; a shared unit does not make distinct instruments one process.
