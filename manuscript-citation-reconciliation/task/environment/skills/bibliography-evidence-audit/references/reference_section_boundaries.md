# Back-matter boundary notes

An exact heading match is stronger than a substring match. Table-of-contents text often appends a page number to the heading. Use the heading occurrence that precedes acknowledgements or the closing project section. Keep the selected heading index and terminating heading index in scratch evidence even when the final report only requires counts.

Bibliography order is a document-local ordinal. A repeated title in two files is not a duplicate finding across files. A repeated entry inside one bibliography should be reviewed as a content issue only when the task asks for duplicate detection; it is not a citation-coverage discrepancy by itself.
