# Numeric citation checklist

Use this checklist while reviewing an extracted body:

1. Confirm the paragraph belongs to the body interval, not the bibliography or a table of contents.
2. Accept a bracket group only when its complete interior is numeric labels separated by citation separators.
3. Keep mathematical intervals, dimensions, page spans, and placeholders out of the citation set.
4. Preserve the literal token for evidence, even if a normalized integer set is used for comparison.
5. Track the two set differences independently and keep empty differences explicit.
