# Scope and coupled work

Read quantities at their actual grain. Equipment counts, component counts and
test items may describe the same package rather than additive assets. A total
across machines does not establish an equal allocation to each machine.

Record conditional links such as replacement plus test as package dependencies.
If the enabling replacement is deferred, determine whether the paired test is
also deferred; do not mark the overall asset complete by performing only the
easier element. Keep separately named areas distinct even when component types
match.

Scope affects the meaning of a date. A completion date for a work package should
include its agreed restoration and handback work, not just the main intervention.
Do not infer unlisted live-operation procedures from a high-level planning table.
