# Staffing and Flow

Use this branch when participant groups cycle through a space, separate activities run concurrently, or staff cover more than one duty.

Build a role-by-time grid from the actual event sources. Treat repeated role listings as potentially the same people until a separate pool is confirmed. For every overlap, check location, travel, admission workload and whether the duty can be interrupted. Assign a primary duty and a conditional secondary duty, or propose relief; never resolve a collision merely by copying a person's name into another row.

Admission connects eligibility to the particular slot, not only to the existence of a reservation. Verify the entitlement, mark its use, count occupancy against the stated limit, then transfer the group to the operating team. Give a full or ineligible group a truthful alternative without changing an approved limit. Reset is a dependency of the following slot: allocate time and ownership for tool recovery, surface cleaning and remaining-material checks.

Breaks must preserve continuous posts. When operations cannot stop, specify relief or staggered breaks with an explicit handoff; off-post meal arrangements do not solve an uncovered safety post.

Check the method against a changed case: if sessions do not overlap, conditional cross-support may be feasible; if they overlap in distant zones, dedicated cover is needed. The correct choice changes with the evidence, not with the format of the previous plan.
