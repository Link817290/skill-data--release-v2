# Equipment changeover criteria

The deterministic checks own the published parameter table, native width
conversions and model-specific pressure starting values. Structured parsing
uses labelled inner/outer values or an explicit equation result; it never takes
the first number from explanatory prose. The source-bound text judge owns
configuration branches, executable sequence, exception/release handling,
first-article closure and the required Chinese operating content. Strict reward
uses the same published split: 30% for the deterministic parameter result and
70% for the weighted semantic operating criteria.

The parameter table receives 30% because wrong width or pressure values can
invalidate setup, but correct numbers alone do not make a safe work
instruction. The semantic operating layer receives 70% because consumable
selection, calibration state, anomaly recovery, first-article acceptance, and
release authority govern whether those parameters can be used without mixing
or releasing unverified labels. The split expresses relative operational risk;
it does not assert that one exact decimal allocation is uniquely correct.

Accept equivalent Chinese wording, reordered sections and any supported procedure
that preserves the job scope and technical prerequisites. Do not require matching
the reference prose or visual style. Numeric mistakes are owned by deterministic
checks; independently unsupported release, false completed trials or prohibited
job changes are semantic failures. A conditional preparation is not production
approval. Reference/source disagreement makes the affected measurement unavailable.

Each independent error has one owner. Configuration owns false technical
capabilities; release/exception handling owns unauthorized process changes and
recovery; first-article checking owns fabricated trial results and incomplete
inspection. Repeated wording or a mechanical consequence is not a second error.

The strict settlement retains every measured leaf once. Deterministic width,
pressure and job coverage checks form the numeric subtotal. The twenty semantic
criteria with positive weights form the semantic subtotal; each owns one
distinct operating decision or recovery obligation. The two subtotals are added
at 30% and 70%. A missing recovery detail therefore loses only its published
atomic weight rather than collapsing an unrelated group. No global exponent or
hidden score cap is applied. Golden completion remains 1.0.

An affirmative decision to release original D by clipping the requested image,
confusing media transport with printable width, or bypassing process approval is
one independent damage event with a 0.4 retention coefficient. Omission does not
trigger it, and repeating the same false release does not create another event.

## Binary lenient reward

Lenient reward is 1 only when the artifacts cover all four jobs, give the
correct B-station pressure, preserve host/power/printhead safety, hold job D
unless a valid alternative is authorized, avoid claiming unperformed trials,
require a consecutive-five-label restart acceptance, and present substantive
operating instructions in Chinese. Equivalent Chinese expression is decided by
the source-bound semantic judge, not by a keyword list.
