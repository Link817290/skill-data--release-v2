# Configuration layers

Build one record per physical unit: exact model, actual resolution or capacity,
installed mechanical options, firmware/menu variant where relevant, and the
configuration evidence. Keep the product family catalogue separate from that
record. A menu choice cannot install a cutter, feed axis, communications card or
other physical option.

For each job join its material, working mode, handling requirement and desired
output to that record. Check both the transport envelope and the working envelope.
The former answers whether stock can be loaded; the latter answers whether the
requested image, machining path or measurement range can be produced. Wider stock
does not expand a narrower working range.

Consumable compatibility includes orientation and material chemistry, not just
dimensions. Distinguish an installed standard part from an optional conversion.
Do not turn an available optional accessory into evidence that it is installed.

Keep mutually exclusive modes explicit. A no-consumable mode is not an instruction
to reuse the consumable from the preceding job. Bind every step to the current
job, especially across a shift that uses multiple machines.
