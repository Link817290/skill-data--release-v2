# Scenario evidence

First establish whether scenarios are mutually exclusive, cumulative, or sampled from a probability model. Independent scenarios cannot be added into one operational demand total. Without probabilities, a worst-case result is not an expected outcome.

Apply scoped revisions, investment additions and outage overrides according to their documented semantics. Assert invariants after every transformation. A closed candidate facility stays closed outside the activating plan; a full outage remains unavailable after capacity additions if the outage applies to all equipment.

Take worst-case values separately for each metric. The scenario with the lowest priority fulfillment need not be the scenario with the lowest overall fulfillment. Preserve the declared objective order when comparing complete plans.

Check budget feasibility in the quotation's unit. Repeated total prices on component rows may describe a single package rather than several payable items. Confirm the commercial grain before aggregation.

Useful incorrect-algorithm replays include retaining a superseded capacity, applying outages before additions, counting orders as minutes, removing a secondary resource constraint, reversing objective priorities, ignoring physical closures, and making directed roads bidirectional. Use only cases relevant to the model at hand. Record whether each mistake changes feasibility, objective values or the recommendation; do not assume it must change all three.

For report review, distinguish numerical verification from presentation review. Use machine checks for reconciliations and an actual visual review for clipped tables, unreadable type, misleading maps or unsupported narrative. Preserve reviewer inputs and raw responses; an incomplete response is not a completed judgment.
