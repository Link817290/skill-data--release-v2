# Independent verification and concise delivery

## Check a different boundary

Re-reading a solver summary through the same parser can reproduce its error. Use a separate table-extraction route, state reconstruction, path calculation or improving-solution search at the vulnerable boundary. Recompute resource usage from actual assignments and travel cost from legal directed segments. Explain which assumptions the independent route tests.

## Exercise the method

Pair an intentional error with a legitimate variation. A missing resource constraint should admit an infeasible solution; shuffling rows should preserve meaning; a different feasible equal optimum should remain valid. Record which part changes and why. Keep these small method checks separate from the actual operational records.

Trace an error to its origin before fixing downstream totals. A source-reading error and a summary that does not reconcile to its own detail are different problems. A failed parsing step leaves affected calculations unverified; it does not establish that all conclusions are false. Recompute the affected descendants after repair.

## Honor the handover contract

Use the requested filenames, output directory, field labels, units and formats exactly where specified. Within that interface, choose a clear organization that preserves the evidence. Do not invent additional deliverables or depend on a local absolute path from the development machine.

Give the reader a concise conclusion and inspectable supporting records. Keep scratch files, debugging logs and redundant exports outside the delivered set. Code should read the stated inputs and create the documented outputs when run from the published command; verify from a clean output directory.

Check every consequential reference: a supplied attachment must exist, and an optional regenerated artifact needs a working command and output location. A PDF and editable Word source are two forms of one report; supply the requested one unless both were requested. Render the saved document to inspect clipping, table continuation and units after layout changes.

Distinguish a proven optimum over listed alternatives, a feasible best-known result and an implemented decision. Conditional mathematical optimality does not establish site readiness, approval or actual service performance. State the resolving evidence for those prerequisites without inventing completion.
