# Notice changes

Use a timeline with separate business-action and publication dates. Choose the historical cutoff requested by the task; a current webpage banner is not evidence of the status at an earlier cutoff.

An amendment has a target scope. Apply additions as a union with the previous effective scope. Replace only the explicitly superseded subset. A repeated item confirms coverage; it does not create a second physical product. Keep the first inclusion and later supporting records when useful.

Compare normalized product variants before counting changes. A table listing all sizes for several amended brands may contain mostly unchanged sizes. Preserve unchanged brands omitted from that partial table.

For downstream notices, retain their own processing company, product descriptions, coding and date windows. Evidence that one supplier provided ingredients to a processor establishes a business relationship, not a complete input-output lot mapping. Do not intersect downstream dates with an upstream retail sales period merely because both concern the same ingredient.

If notices genuinely conflict, preserve both assertions and identify the unresolved dimension. Seek explicit correction or hierarchy evidence; neither later publication nor a broader range automatically authorizes silent overwriting.
