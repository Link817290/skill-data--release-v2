# Evidence cluster checklist

Fill this in cluster by cluster for each sample. **Fill the clusters first, label second.**

## Trend cluster (directional)

- [ ] Does the medium-horizon return cross its percentile cut line? Does the near-horizon return contradict it? (They must agree; a single-window jump is not persistence.)
- [ ] Does the breadth proxy cross its line?
- [ ] Does the earnings proxy cross its line?
- [ ] **Watch out**: check whether these three are collinear. If the field notes say one is composed from price and breadth, it is not independent evidence.
- [ ] Sum the three votes: net `>= +2` emits positive and net `<= -2` emits negative; otherwise record "no direction". A split such as `[+1,+1,-1]` is neutral, not positive.

## Odds cluster (directional)

- [ ] Drawdown deep enough and valuation percentile low enough → bottom odds (positive)
- [ ] Valuation percentile high and equity risk premium low → valuation stretch (negative)
- [ ] Equity risk premium high and valuation not expensive → relative attractiveness (positive)

## Liquidity cluster (directional)

- [ ] Turnover liquidity expanding → positive; turnover shrinking with price falling → negative
- [ ] Credit easing at the margin → positive; no easing plus weak relative attractiveness → negative
- [ ] **Watch out**: if the credit proxy is never negative in this sample, "tightening" can only be expressed as "no easing" — find another condition rather than abandoning the dimension.

## Event cluster (intensity only)

- [ ] Is policy intensity in its high band?
- [ ] Does event noise cross its line?
- [ ] Does volatility cross the shock line?
- [ ] Hitting any one of these records one unit of intensity. **Do not read a direction from it.**

## Style

- [ ] Does the style dispersion cross its line? This is structural evidence used to pick the rotation action; it does not count toward any cluster's direction.

## Convergence check before the evidence set is final

Do this after the clusters above are filled in. **Do not finalise as you go.**

- [ ] Has every dimension that moved this period been listed, including the ones judged unimportant at the time?
- [ ] Did every selected ID actually cross its cut line — rather than sit close to it, or matter narratively?
- [ ] Did collinear dimensions contribute only one cluster direction, while retaining every triggered anchor ID in the complete sets?
- [ ] Does the reported change set include every appeared/disappeared anchor, even if deleting that anchor would leave the final label/action unchanged?
- [ ] Sweep across all samples: were comparable moves of comparable size handled the same way? If one sample recorded it and another did not, go back and make them consistent.
