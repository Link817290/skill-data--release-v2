# Source-Bound Voice Resolution

`judge.mjs` appends evidence-bound resolutions for unknown role observations,
or established source identity with failed expression/placement. Other results
pass through without an additional provider call. Base records are retained.

```sh
node tests/audio_resolution/judge.mjs --mode fresh --refresh --artifact OUTPUT --base-result BASE/llm_judge_result.json --output LOGS/resolution --cache-dir EXTERNAL_CACHE
node tests/audio_resolution/judge.mjs --mode replay --artifact OUTPUT --base-result BASE/llm_judge_result.json --output LOGS/resolution --cache-dir EXTERNAL_CACHE
```

The declared verifier image includes waveform extraction, actual packaged-asset
characterization and their pinned dependencies. Resolution uses real candidate
and source measurements, actual frames, bounded source-line quotations and
hashed asset evidence. Identity, meaningful original expression, and narrative
placement are independent verdicts. Graphic or visual casting defects are not
charged again as audio misplacement. Actual wrong-beat routing still fails.

Private reference energy coverage remains diagnostic; it never defines required
crop length or business credit. Reasonable trims, silence removal and gain
normalization are allowed. Real replacement, loss of key original expression or
wrong role/emotion remains a failure. Effects and background music need not
replicate Golden recipes. Missing or unresolved evidence is an infrastructure
error, not a fabricated candidate zero. API settings and external replay-cache
usage match the parent verifier README.
